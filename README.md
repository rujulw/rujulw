## what im working on

- **atlas**: a self-hosted personal cloud platform built with FastAPI, PostgreSQL, Docker, React, and TypeScript. Current work includes rotating refresh-session auth, owner-scoped file APIs, and the private platform foundation for future internal apps.
- **quadrata64**: a real-time multiplayer chess platform built with React, TypeScript, `ws`, and `chess.js`. The system uses server-authoritative room state, typed websocket messages, waiting-room readiness, synchronized clocks, and validated move broadcasts.
- **timbre**: a Spotify analytics app with a Spring Boot backend and React frontend. The backend owns OAuth and Spotify orchestration, while the frontend focuses on dashboard, player, and hydrated client state.
- **tacet**: an end-to-end encrypted messaging app built with React, Socket.IO, Express, and MongoDB. It includes JWT-based auth/session restore, client-side NaCl encryption, realtime chat transport, and a structured routed workspace.
- **nodus**: a privacy-focused video discovery platform built with Fastify, TypeScript, Prisma, PostgreSQL, and React. It is centered on explainable recommendations, event-driven preference modeling, and portable algorithm profiles instead of opaque ranking.
